# Notanda 1.3.0 — Installer Preview 1

> **Technical pre-release — not the recommended installation path for non-technical users.**

This page publishes the already-built and technically validated standalone installers for Notanda
1.3.0. It exists primarily to make the installer form publicly available and documented for the
SignPath Foundation Open Source code-signing application. **This is not the promoted Notanda beta
page.**

## Important security / trust notice

- **Windows:** `Notanda-1.3.0.msi` is currently **unsigned**. Windows may display a
  **Microsoft Defender SmartScreen** warning.
- **macOS:** `Notanda-1.3.0.dmg` is **ad-hoc signed only**. It is not Developer-ID-signed and is
  not notarized. macOS may display a **Gatekeeper** warning.
- **Linux:** `harvester_1.3.0-1~ubuntu-noble_amd64.deb` is currently **unsigned**.

These warnings are expected for this preview. Do not interpret the presence of this release as
SignPath approval or as a signed production release.

For macOS Gatekeeper handling, see:
https://github.com/RudiRegenwurm/Open-Access-API-Harvester/blob/main/INSTALL-MACOS.md

## Recommended beta access

The recommended, accompanied Notanda beta path remains **exclusively**:

**beta@notanda.io**

This Installer Preview is not being sent or promoted to the existing non-technical pilot users or
to prospective new testers.

## What the installers provide

The preview packages the existing local Notanda control center as an installable application.
Users do not need to install Python manually or start Notanda from a terminal. On first launch,
Notanda opens the local control center; if no OpenAlex API key is configured, the setup path leads
to Settings so the key can be entered and stored locally.

User-owned corpus/state/report data is kept outside the installed application under the user's
Notanda data root.
